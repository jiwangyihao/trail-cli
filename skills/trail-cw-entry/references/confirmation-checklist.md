# Confirmation Checklist

## 开局前必问清单

- [ ] 开新局还是继续上一局。
- [ ] 想上分还是更偏速刷奖励。
- [ ] 走标准还是超频。
- [ ] 继续当前职级、先降到更低、回最高职级，还是指定某个 `AX-X` 层级（公开范围 `A0-1..A8-40`，例如 `A7-3`）。
- [ ] 先按攻略/阵容玩，还是先看投资环境/词条。
- [ ] 是否允许刷开局。
- [ ] 如果检测到未收尾进度，要继续还是先结算。

## 确认后的一般下一步

- 一般先用 `cw enter` 进入货币战争首页，把当前请求落到开局前决策点。
- 当模式、目标与是否继续旧局已经明确后，再用 `cw start` 真正推进到投资环境页并开局。
- 如果用户要先看投资环境，再继续走 `portal.*`。
- 如果用户要先按攻略/阵容走，再继续走 `guide.*`。
- 只有在这些确认项已经问清之后，才应该进入 `cw enter` / `cw start` / `portal.*` / `guide.*` 的具体动作链路。
