# Command Surface

这里讲的是攻略相关命令家族该怎么分工，不是参数手册。

## 候选筛选

- `guide list cw` 负责先列出候选攻略，用在“我想先找几套可能的路线”这个阶段。
- 它适合在已知投资环境、羁绊方向或角色方向时缩小范围。

## 内容确认

- `guide fetch cw` 负责读取完整攻略内容，用来核对标签、阵容、运营思路、投资环境和版本。
- 如果只是要决定“选哪套攻略”，通常到这里就够了。

## 真正进入游戏后

- `cw guide apply` 只在攻略已经选定、并且真正进入游戏后才有意义；不要一上来就 apply。
- `cw guide current` 只在已经 apply 之后，用来回看当前对局实际挂着哪套攻略。

## 交回入口

- 攻略选定后，把后续开局动作交回 `trail-cw-entry`，再走 `cw enter` / `cw start`。
